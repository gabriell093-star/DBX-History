# DBX History — S1

Website arsip kompetitif komunitas Death Battle Xtreme berdasarkan PRD dan UI/UX Requirements v1.0 (27 Oktober 2026).

## Stack
HTML, CSS, JavaScript ES modules, Supabase Postgres/Auth/RLS/Storage.

## Menjalankan lokal
Jalankan `python -m http.server 4173` dari root repository lalu buka http://localhost:4173.

## Admin
Buat akun di Supabase Auth lalu tambahkan UUID yang disetujui ke `public.admin_users`. Login tidak otomatis memberi izin admin.

## Prinsip data
Tidak ada data kompetitif rekaan. Gelar hanya tampil jika terverifikasi; statistik hanya memakai data yang tersedia. Founder: Gabriel dan Daffxy. DBX History adalah arsip komunitas, bukan kanal resmi penyelenggara.
